**THE WORLD TODAY — Tuesday 17 November 2026.** One 1024×1024 newspaper front page that sums up the day's world news in a single image: the US strike on Iran's Qeshm Island and the burning tankers of Hormuz, Trump–Xi–Putin converging on Shenzhen for APEC, Alaska called for Peltola (Senate settled 56–44), the Kerch Bridge struck and closed, the West pressing Israel to open Gaza's crossings, and six one-line briefs from Ireland to the U19 Asia Cup. The image (`news.png`) is drawn by `generate.py`, a deterministic Pillow program — same bytes on every run, no network. The entry program `main.py` copies it to `/output/entry.png`, as the bounty brief allows.

## Run it

```sh
python3 main.py        # writes /output/entry.png
python3 generate.py    # regenerates news.png deterministically
```
